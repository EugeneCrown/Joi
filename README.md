# Joi (Джой) 🧠

**Персональный ИИ‑ассистент**, работающий на собственном сервере (M5Stack Tab5 + бек‑сервер).

## К чему стремимся
- **Голосовое взаимодействие**: активное прослушивание (`wake‑word`), распознавание речи (Whisper‑cpp) и синтез (Piper).
- **Обработку запросов**: по‑умолчанию используется **облачная** модель через `proxyapi.ru`; при недоступности облака автоматически **переключается** на локальную LLM (qwen2.5 1.5 B) через Ollama.
- **IoT‑управление**: управление периферией M5Stack (GPIO, BLE, Wi‑Fi) и обмен данными с сервером через REST‑API.
- **Память и контекст**: хранение короткосрочного и долгосрочного контекста в tier‑структуре SSD/HDD.
- **Безопасность и расширяемость**: система подсказок (system, safety, routing, memory) и возможность подключения пользовательских модулей.

## Что уже есть
- **Конфигурация**: `config/server.yaml` (параметры сервера, хранилища, моделей) и `config/voice.yaml` (wake‑word, STT, TTS).
- **Готовый скрипт установки**: `scripts/setup_voice_on_server.sh` (устанавливает `pvporcupine`, `whisper.cpp`, `piper`).
- **Toolchain**: `scripts/install_toolchain.sh` устанавливает Arduino‑CLI и ESP32‑C6 core.
- **CI/Make‑файлы**: `Makefile` со всеми целями (`install`, `test`, `check`, `storage`, `setup‑voice‑server`, `install‑toolchain`).
- **Проектный план**: `PROJECT_PLAN_RU.md` с разбивкой по этапам (M1‑M7).
- **Документация**: исходные markdown‑файлы в каталоге `docs/`, собираются `mkdocs` (`make docs`).

## Где находится документация проекта?
- Исходники **Markdown** находятся в каталоге **`docs/`** (разделы: `architecture`, `guides`, `reference` и др.).
- Сгенерированный сайт можно собрать командой `make docs` и открыть локально `make docs-serve` (по адресу `http://127.0.0.1:8000`).
- Для быстрого доступа к плану и текущим задачам см. `PROJECT_PLAN_RU.md`.
