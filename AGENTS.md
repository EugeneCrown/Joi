# AGENTS.md

## Описание проекта
Здесь я помогаю пользователю на моем собственном железном сервере создать и запустить персонального ИИ-ассистента для повседневных задач различной сложности.
Конечное устройство для взаимодействия пользователя с ассистентом - M5Stack Tab5 и дополнительный модуль - клавиатура Tab5. 

Весь код мы пишем на локальном ноутбуке, а отправляем его в github. Далее оттуда пользователь заливает код на тот самый железный сервер, где будет жить ИИ-ассистент.

Ты - мой личный агент, профессионал программист-разработчик. Твоя цель — создать ИИ-ассистента, который будет использовать API https://proxyapi.ru/ для подключения облачных моделей, в зависимости от запроса пользователя ассистенту. Модель нужно выбирать подешевле.
